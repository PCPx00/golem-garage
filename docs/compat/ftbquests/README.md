# FTB Quests chapter

A ready-made Golem Garage chapter for modpacks using FTB Quests 2101.x (Minecraft 1.21.1).

Copy `chapters/golem_garage.snbt` into your pack's `config/ftbquests/quests/chapters/` and merge the lines of
`lang/en_us.snbt` into `config/ftbquests/quests/lang/en_us.snbt`, then run `/ftbquests reload`.

The chapter has 16 item quests, from the manual and your first frame through the Garage, Fabricator, Tablet,
War Horn, rigs, the Garage Radio and Cubs. Move, reword or add rewards in the in-game editor as you like.
